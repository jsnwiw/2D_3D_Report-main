# 📊 3D & 2D 인터랙티브 데이터 분석 및 시각화 시스템
> **⚡ Vulkan & WebGPU 차세대 GPU 가속 파이프라인 | 🌓 다크·라이트 테마 | 🎨 Glassmorphism 일원화 UI 탑재**

사용자가 업로드한 CSV 및 엑셀(.xlsx, .xls) 데이터를 자동으로 분석하여 최적의 3D 공간 시각화 및 2D 대시보드로 즉시 렌더링하고, 원클릭 AI 맞춤 분석 및 A4 인쇄 보고서를 생성하는 고성능 반응형 웹 플랫폼입니다.

---

## ✨ 최신 업데이트 하이라이트

- **🌓 다크 모드 / 라이트 모드 (One-Click Theme Toggle)**:
  - 상단바 및 모바일 바를 통한 원클릭 테마 전환 지원 (`localStorage` 설정 영구 보존).
  - 테마 전환 시 3D 배경색, Fog 밀도, 바닥 그리드(GridHelper), 툴팁, 2D 차트, 모달 및 대시보드 폰트/대비가 실시간 자동 동기화됩니다.
- **🎨 Glassmorphism 디자인 시스템 전면 통일**:
  - 버튼 높이(`32px`/`34px`), 테두리 반경(`--btn-radius: 7px`), 포커스 링, 트랜지션 애니메이션 일원화.
  - 상단 글로벌 컨트롤 바, 독립 데이터 소스 카드, 우측 대시보드 드로어, 좌측 2D 차트 패널의 UI 토큰 일치.
- **📌 상단바 최우측 [☰ 메뉴] 버튼 고정**:
  - 좁은 화면이나 모바일에서 상단바가 가로 스크롤되어도 메뉴 열기 버튼이 항상 우측 끝에 고정되어 즉시 접근 가능.
- **🔒 전역 뷰포트 고정 & 독립 스크롤 최적화**:
  - 웹사이트 전체 바운스 스크롤을 방지하여 3D 캔버스를 안정적으로 조작하면서, 대시보드·모달·차트 패널 내부는 매끄럽게 독립 스크롤 작동.
- **📁 엑셀(.xlsx, .xls) & 한국어 인코딩(EUC-KR) 완벽 지원**:
  - SheetJS 라이브러리를 내장하여 CSV뿐 아니라 엑셀 파일도 드래그앤드롭으로 즉시 파싱.
  - EUC-KR / CP949 / UTF-8 자동 감지 및 수동 선택 지원으로 한글 깨짐 방지.

---



- **Vulkan / Direct3D 12 저수준 하드웨어 파이프라인**: 
  - 브라우저 표준 차세대 저수준 그래픽스 API인 **WebGPU** 및 **Three.js WebGPURenderer**를 기반으로 작동합니다.
  - Windows 시스템에서 **Vulkan / Direct3D 12** 백엔드와 직접 통신하여 기존 WebGL 대비 드라이버 오버헤드를 획기적으로 낮추고 CPU-GPU 병목을 해소합니다.
  - **WGSL (WebGPU Shading Language)** 네이티브 셰이더 파이프라인을 통해 대량의 3D 데이터 객체도 60~120 FPS로 안정적으로 렌더링합니다.
- **실시간 GPU 하드웨어 모니터링 HUD**:
  - 상단 바의 `⚡ Vulkan / WebGPU` 뱃지를 클릭하면 현재 구동 중인 GPU 어댑터 명칭, 제조사, 아키텍처 및 실시간 FPS / 프레임 타임 스파크라인 그래프를 바로 확인할 수 있습니다.
- **무중단 스마트 자동 폴백 (Graceful Fallback)**:
  - 구형 브라우저이거나 WebGPU가 비활성화된 환경에서는 자동으로 고안정성 **WebGL 2.0 세이프 모드**로 전환되어 호환성 문제를 원천 차단합니다.

## 🚀 주요 기능

### 1. 지능형 데이터 분석 & AI 인사이트
- CSV / Excel 업로드 즉시 각 열의 데이터 타입(수치, 날짜, 범주) 자동 판별.
- 기술 통계량(평균, 최대, 최소, 표준편차, 사분위수) 및 이상치(Outlier) 자동 탐지.
- **1-Click AI 맞춤 분석 보고서**: 데이터 패턴에 맞춰 A4 인쇄 규격의 전문 비즈니스 보고서 자동 생성 및 PDF 출력 지원.

### 2. 10종 3D 공간 시각화 스타일
- 📊 **3D 원기둥 / 직육면체 막대 (cylinder / box)**: 범주별 수량 및 규모 비교
- 🔺 **3D 피라미드 타워 (pyramid)**: 손실·비용 및 계층별 지표
- 🍩 **3D 도넛 링 / 파이 슬라이스 (donut / pie)**: 비율 및 점유율 구조 분석
- 📈 **3D 입체 튜브 라인 (line)**: 시계열 추세 흐름 분석
- 🏔️ **3D 산악형 면적 차트 (area)**: 볼륨 및 누적 분포 시각화
- 🌐 **3D 입체 산점도 (scatter)**: 다변량 상관관계 좌표 분석
- 🌊 **3D 곡면 서피스 (surface)**: 지형 맵 형태의 데이터 밀도 분포

### 3. 정밀한 3D ↔ 2D 양방향 인터랙션
- **레이캐스팅(Raycasting)**: 마우스/터치 호버 시 1.08배 스케일 확대 및 Emissive 발광 피드백.
- **화면 투영 동기화**: `Vector3.project(camera)` 기반으로 3D 월드 좌표에 맞춰 플로팅 툴팁 및 3D 바닥 라벨 추적 표시.
- **클릭 하이라이트**: 3D 개체 클릭 시 카메라가 부드럽게 줌인(Lerp)되며 2D 틀고정 데이터 테이블 및 미니 통계 차트와 즉각 연동.

### 4. 사용자 맞춤형 대시보드 컨트롤
- X축(기준 라벨), Y축(수치 지표) 동적 지정.
- 실시간 키워드 검색, 상위 N개(Top 10, Top 30) 렌더링 최적화, 수치 범위(Min~Max) 필터링, 정렬 기능.
- 3D 정밀 환경 설정: 환경광, 직사광, 포인트 라이트 강도 및 색상 틴트, 노출(Exposure), 카메라 FOV, 안개(Fog) 밀도, 실시간 그림자 On/Off, 배경색, 10종 그라디언트 테마.

### 5. 보조 2D 차트 & 틀고정 데이터 테이블
- 8종 2D 차트(세로/가로 막대, 도넛, 파이, 폴라, 라인, 산점도, 레이더) 동시 연동.
- 첫 번째 열 및 헤더가 고정(Sticky)되는 양방향 스크롤 데이터 테이블 제공.

## 💻 사용 방법

1. **실행**: 웹 브라우저에서 `index.html`을 열거나 웹 서버로 호스팅합니다 (별도 백엔드 설치 불필요).
2. **데이터 로드**: 좌측 상단 [데이터 소스] 패널에서 CSV 또는 엑셀 파일을 선택하거나 화면에 드래그앤드롭합니다 (인코딩 자동 감지).
3. **탐색**:
   - 마우스 좌클릭 드래그: 3D 회전
   - 마우스 우클릭 드래그: 3D 이동 (Pan)
   - 마우스 휠: 줌 인/아웃 (상단바 위에서는 가로 스크롤 동작)
   - 메쉬 클릭: 상세 정보 카드 및 데이터 테이블 하이라이트
4. **테마 변경**: 상단바의 `🌓 다크/라이트` 버튼을 클릭하여 테마 전환.
5. **보고서 출력**: 상단바 [📄 보고서] 또는 대시보드의 AI 맞춤 분석 보고서 버튼을 클릭하여 인쇄 및 PDF 저장.

- **서비스워커 캐시 버전 업데이트**: `3d-vis-cache-v15` 로 상승해 최신 파일 강제 로드.
